# 企业信任中心运营契约

`trust.proof-center` 的唯一事实源是已验证信任资产库：`来源与权利引用 → 证据资产登记 → 有效期和陈述范围异人核验 → 页面交接提案 → 异人批准 → 页面责任人回执`。认证、检测、服务保障、产能与交付证明必须绑定 `agent_path`、`tenant_id`、`client_id`、`plan_id` 和 `project_id`。

## 三端职责与边界

总部登记证明来源、权利范围、适用市场和失效日期；代理独立核验来源仍有效且页面陈述不超出证明范围；客户市场、销售或质量责任人接收经批准的页面交接。系统不伪造证书、检测、产能、客户案例或交付承诺，不自动发布网站，不复写企业资料或内容主档。

## 共享对象事件契约

后续实现将冻结 `proof-center-verified-asset` 对象和 `proof-center-handoff-released` 事件。迁移回滚只能删除本应用的信任资产治理投影、权限和契约，绝不删除来源文件、企业资料、产品事实、客户站点或下游已执行工作。

## 升级门槛

当前 `/company-info?tab=service` 仅有服务保障内容投影，保持 `pilot`。正式可用前必须具备租户模型、权限审计 API、迁移回滚、失效证据拦截、三端回执、自动化测试、真实页面验收、生产构建与 H 版本证据。
