# AI 本地化分发运行契约

本应用不把机器翻译直接发布到社媒。它只把总部已批准的社媒内容与已发布国家内容包组合成目标市场、语言和渠道的分发清单，并固定两端指纹。

## 闭环

创建要求已批准社媒审核记录和已发布国家内容包；独立角色核验后，再由第三角色生成不触发第三方调用的发布清单，最后由独立接收方确认。所有动作由 `factory.deepen.localized-distribution.*` 权限、租户/项目访问和审计保护。

## 边界与回滚

清单记录 `external_publish_dispatched=false`，不保存 OAuth 或原始凭据。迁移 `d8b5f1c2a704` 的回滚只清除本应用投影、权限和对象/事件契约，不删除社媒审核、DAM 素材、版权、术语、国家内容包及审计记录。
