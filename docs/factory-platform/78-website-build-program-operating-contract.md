# 02.布场（内容）｜建站总控运营契约

`WebsiteBuildProgram` 是客户网站从策略到运营的项目级事实源；它关联既有的多站管理、内容版本、发布回执和运营工作流，而不复制 CMS 内容、域名凭据或前端代码。

## 业务链路

`站点策略 → 内容与素材 → 可视化与响应式 → 多语言与路由 → 转化与数据 → 发布与恢复 → 7/30/90 天运营`。

创建时必须记录工厂的目标受众、价值主张、转化目标、导航模板、B2B/B2C/混合模式、市场范围、语言和路由策略。路由只允许 `subdomain`、`path` 或 `single`；域名仍由多站管理保存引用号，绝不保存注册商密钥。

## 三端共享契约

- 总部维护标准门禁、对象和事件契约；不代替客户发布网站。
- 计划源建立项目、绑定客户站点空间并维护过程证据。
- 客户端只能在其项目范围内查看和确认交付；不能跨项目读取站点、门禁或发布记录。
- 可视化页面复用共享 Card、Button、Badge 和响应式栅格，不复制全局样式；所有按钮调用同一租户 API 并由项目权限和审计保护。

## 安全与发布边界

每个门禁必须由创建人以外的角色核验。仅当七项门禁全部通过，且建站项目配置的**每一种语言**都在同一站点具有“已批准并收到下游回执”的内容发布记录时，另一独立角色才可把项目激活为正式运营。任何缺失语言都会阻断激活并返回语言清单；每种语言保留独立的内容版本、发布、回执与回滚标识。激活只记录运营交付证据，不会直接部署、覆盖、删除或回滚公共网站。

权限：

- `factory.content.website-build.program.manage`
- `factory.content.website-build.gate.verify`
- `factory.content.website-build.activate`

对象契约：`website-build-program`。事件契约：`website-build-activated`。迁移 `a01b2c3d4e5f` 的降级仅删除本应用的项目、门禁、权限和契约；绝不删除站点、内容版本、发布、域名、素材或公共网站。

## 验收
