# 四档商业套餐与价值交付规范

商业套餐用于组合十二类能力、优先专项、权限、实施和服务范围。套餐不是第13类，也不是客户、订单、财务或产品权益的业务事实源；授权事实由价值交付底座管理，业务事实仍由对应类别管理。

程序事实源为 `FACTORY_PLATFORM_COMMERCIAL_PACKAGES`。

## 套餐矩阵

| 套餐 | 覆盖范围 | 主要结果 | 必须证明 |
| --- | --- | --- | --- |
| 获客版 | 01—04 | 产品定位、数字阵地、搜索信任、AI推荐基础 | 上线周期、有效收录、事实完整度 |
| 增长版 | 01—08＋智能报价 | 内容流量到画像、询盘、报价和成交 | 有效询盘率、响应报价周期、询盘转化 |
| 经营版 | 01—12＋智能报价、价值证明、客户资产 | 营销、成交、履约、客户、财务、决策闭环 | 履约追溯、毛利现金、复购价值 |
| 全球版 | 经营版＋全部优先专项 | 全球内容、产品护照、碳贸合规和智能治理 | 国家包、产品合规、跨境和AI审计 |

## 套餐装配规则

1. 套餐只引用蓝图应用ID、优先专项ID和版本，不复制应用定义。
2. 栏目开通不等于交付成熟；规划能力即使包含在套餐中也必须继续显示“规划”。
3. 试点必须写明客户、区域、连接器、期限、数据范围、支持责任和退出方案。
4. 已具备必须绑定当前版本、验收证据、监控和回退记录。
5. 降级套餐不得删除业务数据，应撤销能力授权并保留合同要求的导出和保留期。
6. 任何效果承诺必须写明基线、周期、样本、口径负责人和客户配合条件。

## 计费口径

应用立项时只能从明确口径中选择计费方式：订阅、席位、站点、用量、交易、连接器、实施或服务。一个应用可组合计费，但必须声明计量事件、去重规则、时区、退款调整和对账责任。

不得用页面访问量冒充AI调用量，不得用报价数量冒充成交交易量，也不得让套餐系统直接修改财务正式金额。

## 客户价值证明

每个套餐上线前建立基线，上线后按固定周期比较：内容上线时间、搜索可见度、有效询盘率、回复时间、报价周期、成交率、准时交付率、库存周转、现金转换周期、复购率、毛利和客户终身价值。

价值证明只能读取权威业务事实。客户未授权的案例、品牌、数据和结论不得用于公开销售材料。
