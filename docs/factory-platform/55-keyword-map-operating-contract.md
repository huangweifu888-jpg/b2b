# 03.营搜｜关键词主题地图运营契约

`trust.keyword-map` 以 `来源与观测日期 → 不可变主题版本 → 异人核验 → 可回退交接 → 异人批准 → 消费者回执` 管理关键词规划。所有记录绑定 `agent_path`、`tenant_id`、`client_id`、`plan_id` 与 `project_id`；搜索量、难度和排名均不构成承诺。

## 受控交付链

总部只建立可追溯的市场、数据来源和观测日期；代理在获授权范围内进行独立核验与批准；客户内容、SEO 或销售团队必须以回执接收交接。主题地图是可审计的规划输入，不是流量购买、排名保证或对客户站点的直接写入授权。

## 数据、权限与回退

迁移 `8d6f3a2b1c95` 建立研究、版本、发布和证据投影，冻结对象 `keyword-topic-map-version` 与事件 `keyword-topic-map-released`。回滚只移除本应用投影、权限和契约，绝不删除来源数据、客户内容、搜索平台配置或消费者工作。

## 可用性证据

总部负责来源与发布门禁，代理负责获授权范围的独立核验/批准，客户内容、SEO 或销售端以回执接收交接。`/seo?tab=keywords` 保留原关键词表，只增加共享治理面板；不自动创建内容、购买流量或修改客户站点。

升格为 `available` 前必须通过 `test_factory_keyword_map.py`、升级→回滚→再升级演练、总部/代理/客户真实 API 回执、页面 `live` 状态、六步动作、无横向溢出、生产构建和 H 版本同步。
